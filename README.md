Pension and Social Grant Payment Tracking System

Windows Forms (C#) desktop app with MySQL, built with the MVC pattern.

Setup
1. Start MySQL in XAMPP.
2. In phpMyAdmin, open the SQL tab (with no database selected) and run database.sql. It recreates the database.
3. Open PensionGrantTracker.sln in Visual Studio.
4. In Controllers/DbHelper.cs, check the password in the connection string (XAMPP root has an empty password).
5. Press F5.
